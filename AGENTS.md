## Agent skills

### Issue tracker

Issues 放在 GitHub Issues（holmeslin/learning-go-to-senior），用 `gh` CLI 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

使用預設的五個標籤：needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目錄一份 `GLOSSARY.md`，ADR 放在 `docs/adr/`。See `docs/agents/domain.md`.
